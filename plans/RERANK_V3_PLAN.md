# План: v3-отбор контекста (свой rerank на стороне бота)

> Статус: решения согласованы (2026-10-17), ждёт утверждения и реализации.
> Режим: сразу боевой, с флагом-выключателем `RERANK_ENABLED`.

## Зачем

LightRAG отдаёт сырой контекст (~40к символов), бот режет его сам: кап на
описания (`LIGHTRAG_CONTEXT_DESC_CAP=1200`) и первые
`LIGHTRAG_CONTEXT_MAX_CHUNKS=12` чанков по порядку сервера. Порядок сервера
слепой к вопросу: чанк из одних фото-тегов может занять слот наравне с фактом.
Серверный rerank отпал — нужен внешний платный провайдер (cohere/jina), а
`rerank_binding='null'`. Решили делать отбор своими руками, бесплатно.

Эксперименты v1 → v2 → v3 на 48 реальных выдачах (dumps/, dumps2/, dumps3/,
сняты боевым запросом бота): покрытие слов вопроса у v3 нигде не ниже
baseline, мусор и пустышки в основном меньше, итог разбора — 4 уверенные
победы / 0 поражений.

## Утверждённые решения (2026-10-17)

| # | Решение |
|---|---------|
| 1 | Сразу в прод. Флаг `RERANK_ENABLED` (по умолчанию вкл); откат = false + рестарт бота |
| 2 | Мусор — мягкий штраф ×0.25 (из промпта не выкидываем, только демоция) |
| 3 | ABSENT — логируем + короткая пометка в промпте («прямых упоминаний нет») |
| 4 | Пустышки (нулевой скор) — заполняют остаток бюджета, «за ту же цену» |

## Как работает v3 (ядро уже написано в tools/)

Из `tools/rerank_compare.py` (там же — v1/v2 идеи из `rerank_exp.py`,
`rerank_v2check.py`):

- токены вопроса: кириллица целиком включая украинские і/ї/є/ґ, стоп-лист
  служебных слов;
- скор факта = сумма по словам вопроса: raw-совпадение весит IDF, стем и
  транслит (RU→EN) — 0.7×IDF (редкие слова весят больше: «максим» ~ везде);
- демоция ×0.25: сущности-даты (`2022-01-31`) и имена в 1–2 символа; чанки с
  <8 живыми словами или 15+ телеграм-тегами. Меры (`100 км`), годы, деньги —
  не мусор;
- порядок: при равном скоре сущности раньше чанков, внутри — как у сервера;
- absence gate: ни одного raw-совпадения во всей выдаче → флаг absent
  (стем/транслит считаются похожестью, а не знанием);
- выбор: сортировка по скору и заполнение бюджета; нулевые добирают остаток.

## Точка встраивания

- `rag_client.py`, `compact_context()` — получает дополнительные аргументы
  `query` (обязателен для скоринга) и `rerank_enabled`; вызов из `retrieve()`.
- Флаг выключен, layout не распознан, скоринг упал или дал пусто —
  сегодняшняя логика как есть (бот не может сломаться из-за v3).
- absent → в конец возвращаемого контекста добавляется строка-пометка
  «прямых упоминаний в базе нет» (уходит в промпт как часть блока фактов).
- `retrieve()` — да, `query_direct()` (триггер !память) не трогаем: там нет
  сырого контекста, LightRAG генерирует ответ сам.
- Логи: `RAG-DEBUG [rerank]` — бюджет, сколько фактов/сущностей/чанков, что
  выкинуто/добавлено vs baseline, absent. Для наблюдения в бою.

## Файлы

Новые:
- `rerank.py` — чистые функции: нормализация/стем/транслит, скоринг, детект
  мусора, absence gate, `select_facts()` (без I/O, легко тестировать);
- `tests/test_rerank.py` — синтетические кейсы (дампы в гит не кладём —
  там содержимое чата).

Изменяемые:
- `rag_client.py` — интеграция в `compact_context()` + логирование;
- `config.py` + `.env.example` — `RERANK_ENABLED` (default true);
- `tools/rerank_compare.py` — импорт скоринга из `rerank.py`: один источник
  правды, повторный прогон обязан воспроизвести те же цифры.

## Шаги

1. `rerank.py`: порт скоринга из tools (украинские буквы добавить) + юнит-тесты:
   raw/stem/translit/IDF, демоция мусора, меры не мусор, gate только по raw,
   бюджет не превышен, порядок стабилен.
2. Интеграция в `rag_client.py` + `RERANK_ENABLED` в конфиг. Тесты: флаг off →
   байт-в-байт сегодняшний вывод; исключение в скоринге → fallback baseline.
3. Parity: `tools/rerank_compare.py` на dumps/dumps2/dumps3 — цифры совпадают
   с текущими зафиксированными (или каждое отличие объяснено).
4. `pytest` — весь проект зелёный (сейчас 110 тестов + новые).
5. Коммит + пуш (по команде) → автодеплой.
6. На VPS: `RERANK_ENABLED` в `.env` можно не трогать (default true). Первые
   живые запросы появятся, когда пополнят OpenAI — сейчас поиск лежит на 429.
7. Наблюдение по логам `[rerank]`; сверка ощущений в чате с пользователем.

## Откат

- Быстрый: `RERANK_ENABLED=false` в `/opt/bot/.env` + рестарт бота (без
  передеплоя; флаг читается на старте).
- Полный: git revert + автодеплой.

## Открытые хвосты

- Пользователь присылает свои кейсы «бот лажал с памятью» → четвёртая партия
  дампов, прогон сравнения на них.
- После чисток графа (rebuild VDB, волна-2 склеек, доки 2022) — переснять
  дампы и повторить parity-прогон: выдачи могли поменяться.
